# Criteria for Visual Assets

## Interpretation
The goal is to generate visual assets for the adult-animation style comedy short. The assets must include 1280x720 scene backgrounds and transparent 2D cutout character sprites with multiple mouth shapes and expressions, matching the script.json and spec.md (irreverent, adult-animation tone). All assets must be packaged in `visuals.zip`.

## Claims
- **C1**: `visuals.zip` exists and contains all required backgrounds and transparent character sprites.
- **C2**: Background images are exactly 1280x720 pixels in PNG format.
- **C3**: Character sprite images are in PNG format with an alpha (RGBA) channel representing transparent backgrounds.
- **C4**: Visual assets representing specific cutaways and gags (barista, bear with badge, router fire) exist.
- **C5**: Assets achieve a visual style score of >= 4/5 according to a fresh Gemini-3.5-pro model evaluation based on the rubric in spec.md.
